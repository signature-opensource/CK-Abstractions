# CK-Abstractions

[![Licence](https://img.shields.io/github/license/signature-opensource/CK-Abstractions.svg)](LICENSE)

The contracts of the CKomposable framework: the marker interfaces and attributes the engine reads to
build the Real Object graph, compose the Poco, configure the DI container and place a package's
resources among the others.

| Package | Description | Latest stable |
|---------|-------------|---------------|
| [CK.Abstractions](CK.Abstractions/README.md) | Real Objects, Poco and Auto Services contracts, plus the assembly-level attributes that scope what the engine looks at. | [![nuget](https://img.shields.io/nuget/v/CK.Abstractions.svg?label=CK.Abstractions)](https://www.nuget.org/packages/CK.Abstractions/) |
| [CK.ResourceSpace.Abstractions](CK.ResourceSpace.Abstractions/README.md) | Which resources a type owns and where it sits among the others: groups, packages and the topology attributes. | [![nuget](https://img.shields.io/nuget/v/CK.ResourceSpace.Abstractions.svg?label=CK.ResourceSpace.Abstractions)](https://www.nuget.org/packages/CK.ResourceSpace.Abstractions/) |
